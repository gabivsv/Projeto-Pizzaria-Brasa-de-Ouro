# 🍕 Brasa de Ouro — Pizzaria

Aplicação web desenvolvida para uma pizzaria, com frontend e backend integrados para disponibilização de funcionalidades relacionadas ao gerenciamento e aos pedidos.

## 📌 Sobre o projeto

O **Brasa de Ouro** foi desenvolvido como um projeto de aplicação web, utilizando uma arquitetura separada entre frontend e backend.

A aplicação está organizada em:

- `frontend/` — interface da aplicação
- `backend/` — serviços e lógica do sistema
